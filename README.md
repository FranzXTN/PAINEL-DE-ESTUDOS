# Painel de Estudos

## 1. Nome e tema do projeto

O projeto se chama Painel de Estudos e tem como objetivo apresentar informações sobre meus estudos, como curso, tarefas concluídas e horas estudadas.

## 2. Explicação da interface

A interface foi criada utilizando HTML e Bootstrap. Ela possui um menu superior, uma apresentação do painel, três cards com informações sobre os estudos, etiquetas de status, um aviso, um botão e um rodapé.

A página foi organizada para funcionar em computadores e dispositivos móveis.

## 3. Componentes Bootstrap utilizados

Foram utilizados os seguintes componentes e classes do Bootstrap:

- `navbar`: cria o menu superior.
- `container`: organiza e centraliza o conteúdo.
- `row` e `col`: organizam os elementos em colunas.
- `card`: apresenta as informações em cartões.
- `badge`: mostra etiquetas de status.
- `button`: cria um botão.
- `alert`: apresenta uma mensagem de aviso.
- `footer`: apresenta o rodapé da página.

O Bootstrap foi conectado por meio de um CDN no arquivo HTML, sem a necessidade de criar um arquivo CSS próprio.

## 4. Diferença entre let, const e var

A declaração `const` é utilizada para criar uma variável cujo valor não pode ser reatribuído. A declaração `let` permite alterar o valor de uma variável. Já `var` é uma forma mais antiga de declarar variáveis. Atualmente, damos preferência ao uso de `let` e `const`.

## 5. Tipos de dados utilizados

No projeto, foram utilizados quatro tipos de dados:

- **String:** representa textos, como o título do painel.
- **Number:** representa números, como a quantidade de tarefas.
- **Boolean:** representa um valor verdadeiro ou falso.
- **Null:** representa a ausência intencional de um valor.

Esses tipos foram utilizados para armazenar e exibir informações no Console do navegador.

## 6. Explicação da condição if/else

Utilizei a estrutura `if/else` para verificar se a meta de horas de estudo foi atingida.

O programa calcula quantas horas faltam para atingir a meta. Se o resultado for maior que zero, exibe uma mensagem informando que a meta ainda não foi atingida. Caso contrário, informa que a meta foi concluída.

## 7. Maior dificuldade encontrada

Minha maior dificuldade foi entender como utilizar as variáveis e as condições `if/else` para verificar os resultados dos cálculos.

## 8. Como a dificuldade foi resolvida

A dificuldade foi resolvida praticando os exemplos, executando o código no Console do navegador e corrigindo os erros durante o desenvolvimento da atividade.

## 9. Arquivos do projeto

- `index.html`: contém a estrutura da página e a conexão com o Bootstrap.
- `script.js`: contém as variáveis, os cálculos, as mensagens e as condições em JavaScript.
- `README.md`: apresenta a documentação do projeto.
